# TaskFlow Project Dashboard

## Project Overview
TaskFlow is a comprehensive task management application designed to check efficient project management, track deadlines, and collaborate seamlessly with Google Calendar.

## Technologies
This project is built with:
- **Frontend**: React, Vite, TypeScript
- **Styling**: Tailwind CSS, Shadcn UI, Google Material Design 3
- **State Management**: Zustand
- **Backend & Database**: Supabase (PostgreSQL, Edge Functions)
- **Deployment**: Vercel

## Getting Started

### Prerequisites
- Node.js & npm installed

### Installation

```sh
# Clone the repository
git clone <YOUR_GIT_URL>

# Navigate to the project directory
cd Dasbroad-v1

# Install dependencies
npm install

# Start development server
npm run dev
```

## Deployment
This project is optimized for deployment on **Vercel**.
1. Push to GitHub
2. Import project in Vercel
3. Configure Environment Variables:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_PUBLISHABLE_KEY`
   - `VITE_SUPABASE_PROJECT_ID`
